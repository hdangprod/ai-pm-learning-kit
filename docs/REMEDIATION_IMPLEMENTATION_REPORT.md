The ZIP at `docs/AI_PM_EDUCATIONAL_AUDIT_20261019.zip` and all18 extracted entries under `docs/educational-audit/` are preserved byte-identically. ## Implemented

**AQ01:** M1–5 answer options have semantic IDs. New practice grades IDs, not displayed positions. Draft order is persisted and fixed during an attempt; first edit after a submitted response creates a new attempt with different ordering, while preserving selected meanings. A stable initial seed avoids modifying untouched legacy records. Original canonical indices remain compatibility fields and the original label catalog is frozen. Thirteen revised distractors target realistic unit, assignment, causal-inference, denominator and premature-decision errors. Numeric keys and source fixtures are unchanged.

**AQ02:** M6's five selected-statement dimensions retain the original0–10 scorer and feasibility/critical gates. A separate **Pending independent review** panel exports a readable packet: all frozen stage memos, actual evidence/scenario, decision/effort/changed facts, selected statements, complete attempts, scores and consultation. Its human worksheet uses five dimensions0–2, critical-error override and explicit acceptance of alternatives/justified keep. No keyword, length, date or selected-choice semantic pass is awarded. A signed external worksheet, not app authentication, is the independent review record. Six authored memo variants are tested and cataloged privately for calibration; none is represented as a learner or human-review result.

**AQ03:** Existing transfers are labeled **Same-case transfer practice**. An offline moderator command creates only the assigned A/B/C form (six tasks), response/calculation/memo artifacts and an exposure/timepoint manifest. Baseline/immediate-post/delayed labels are explicit; yes/no/unknown prior form and answer exposure is required. Original M6 memo is separately archived and hashed before the assigned change card is released; duplicate locks/sessions are refused. Private answer keys remain separate. Vite development denies private docs/materials/assessment URLs, including the original archive; production assets contain no independent forms/keys. This is an offline administration workflow, not a secure exam backend.

**AQ04:** New snapshots record initial unaided, after feedback or after instructor-solution exposure, scoped to same-case practice. Earlier responses never change on retry. Each assisted retry requires a new nonblank account of changed reasoning; M6 binds it to the specific last attempt to prevent reusing an already consumed note. The text is recorded, not semantically graded. Consultation remains sticky after hide/reload. Historical assistance is explicitly unknown rather than inferred from final state. Evidence appears in UI and JSON export; original v1 records remain exact.

See [source findings](AQ01_AQ04_SOURCE_FINDINGS.md), [compatibility](ASSESSMENT_COMPATIBILITY_REPORT.md), [memo rubric](INDEPENDENT_MEMO_REVIEW_RUBRIC.md), and [moderator instructions](ASSESSMENT_ADMINISTRATION.md). AQ05–AQ11 are prioritized in [the deferred backlog](REMEDIATION_BACKLOG.md).
